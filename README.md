# E-Commerce Sales Analysis

## Project Overview

An Excel-based e-commerce sales analysis and interactive dashboard designed to analyze sales performance, customer behavior, and product performance.

## Key Analysis

* Sales Performance
* Customer Analysis
* Product Performance
* Sales Trends
* Category Analysis

## Tools

* Excel
* Power Query
* Pivot Tables
* Data Visualization

## Dashboard

Interactive dashboard built in Excel to explore sales data and identify key business trends.
